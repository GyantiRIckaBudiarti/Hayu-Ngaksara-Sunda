# Hayu Ngaksara Sunda

Game edukasi aksara Sunda untuk PC. Jalan-jalan di lingkungan sekolah, ngobrol sama guru, kerjain latihan baca-tulis-pelafalan — belajar aksara Sunda jadi lebih ada konteksnya dibanding hafal tabel huruf doang.

> *Game édukasi aksara Sunda keur PC. Urang jalan-jalan di sakola, ngobrol jeung guru, latihan maca-nulis-pelafalan — diajar aksara Sunda jadi leuwih karasaeun tibatan ngapalkeun tabel huruf wungkul.*

Dibuat sebagai skripsi di UNIKOM Bandung. Materi berdasarkan kurikulum muatan lokal Bahasa Sunda kelas 5 SD.

## Cara Install / *Cara Masang*

**Bahasa Indonesia**

1. Buka halaman **Releases** di repositori ini, lalu download file `.zip` versi terbaru.
2. Ekstrak isi zip ke folder mana saja di komputer kamu.
3. Masuk ke folder hasil ekstrak, lalu klik dua kali `Hayu Ngaksara Sunda.exe`.
4. Selesai — tidak perlu install apapun, langsung jalan.

Kalau muncul peringatan Windows Defender / SmartScreen, pilih **"More info" → "Run anyway"**. Itu wajar untuk aplikasi yang belum punya sertifikat publisher berbayar.

---

**Basa Sunda**

1. Buka kaca **Releases** di repositori ieu, teras undeur file `.zip` versi panganyarna.
2. Ekstrak eusina kana folder nu dipilih di komputer.
3. Asup kana folder hasil ekstrak, teras klik dua kali `Hayu Ngaksara Sunda.exe`.
4. Réngsé — henteu perlu masang nanaon, langsung tiasa dijalankeun.

Lamun aya peringatan Windows Defender / SmartScreen, pilih **"More info" → "Run anyway"**. Hal éta biasa pikeun aplikasi anu can boga sertifikat publisher.

## Cara Main / *Cara Maén*

**Bahasa Indonesia**

Mulai dengan menemui **Bapak Jajang** untuk tutorial singkat. Setelah itu, tiap level punya tiga latihan yang harus diselesaikan:

- **Membaca** — temui Ibu Sinta
- **Menulis** — temui Bapak Ucup  
- **Pelafalan** — temui Ibu Nabila

Kalau ketiga latihan di level itu sudah selesai, balik lagi ke **Bapak Jajang** untuk naik ke level berikutnya. Panel objektif di layar selalu kasih tahu harus ke mana selanjutnya.

Urutan level: **Tutorial → Aksara Swara → Ngalagena I → Ngalagena II → Rarangken**

---

**Basa Sunda**

Mimitian ku nepungan **Bapak Jajang** pikeun tutorial. Sanggeus éta, unggal level boga tilu latihan anu kudu diréngsékeun:

- **Maca** — tepungan Ibu Sinta
- **Nulis** — tepungan Bapak Ucup
- **Pelafalan** — tepungan Ibu Nabila

Lamun katilu latihan dina level éta tos réngsé, balik deui ka **Bapak Jajang** pikeun naek level. Panel objektif dina layar bakal némbongkeun kudu ka mana salajengna.

Urutan level: **Tutorial → Aksara Swara → Ngalagena I → Ngalagena II → Rarangken**
